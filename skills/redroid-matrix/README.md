# redroid-matrix

Use when controlling the cicy-desktop Redroid 矩阵 panel: create/start/stop/remove redroid Android devices, screenshot, tap/swipe/key/text, proxy, IP grade, frida, apps, adb shell.

Requires the `agent-electron` and `agent-desktop` skills on PATH and a connected
cicy-desktop host. See `SKILL.md` for the full command list.

```sh
redroid-matrix --help
```
