# facebook-matrix

Use when controlling the cicy-desktop Facebook 矩阵 panel: manage Facebook profiles (add/remove/proxy/IP probe) and drive each profile's Facebook web view (select, reload, eval, snapshot, CDP).

Requires the `agent-electron` and `agent-desktop` skills on PATH and a connected
cicy-desktop host. See `SKILL.md` for the full command list.

```sh
facebook-matrix --help
```
