# Commands

```text
install [--dir=D:\path]  Install using the fixed drive with the most free space
start                    Verify NVIDIA runtime and start 127.0.0.1:8771
stop                     Stop the GPU API without deleting data
status                   Show install root, image, endpoint, and runtime status
```

Override the image with `CICY_KOUBO_GPU_IMAGE` and the WSL distro with `CICY_WSL_DISTRO`.
