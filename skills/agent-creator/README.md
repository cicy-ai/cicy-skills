# Agent Creator

Create and manage custom cicy agents (persona + tools + model) via
`/api/custom-agents` on the local cicy-code server. Author a reusable agent
persona once; it then appears as its own agent type (`custom:<slug>`) in the
cicy-code "new worker" picker.

See [SKILL.md](./SKILL.md) for usage and [references/help.md](./references/help.md)
for the full command reference.
