# telegram-matrix

Use when controlling the cicy-desktop Telegram 矩阵 panel: manage Telegram profiles (add/remove/proxy/IP probe) and drive each profile's Telegram Web view (select, reload, eval, snapshot, CDP).

Requires the `agent-electron` and `agent-desktop` skills on PATH and a connected
cicy-desktop host. See `SKILL.md` for the full command list.

```sh
telegram-matrix --help
```
